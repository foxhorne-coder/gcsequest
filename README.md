# GCSEQuest — AQA Revision

A GitHub Pages revision site for AQA GCSE Biology, Chemistry, Physics, Maths and AQA Level 2 Further Maths.

## Included
- Year 10 and Year 11 filtered course views (GCSEQuest suggested split; AQA specifications are linear)
- Topic revision tracker with Revised / Not Revised status
- Progress saved locally and synced to the signed-in Google account through Firebase Firestore
- Interactive lesson tabs, flashcards and quick checks
- Timed tests, XP and scoreboard
- Official AQA past-paper finder links
- Google sign-in with Firebase Authentication

## Firebase
The Firebase web configuration is already included in `firebase-config.js`. Google Authentication should be enabled and `foxhorne-coder.github.io` should be an authorised domain.

## GitHub Pages
Upload the files in this ZIP to the root of the `gcsequest` repository and deploy the `main` branch from `/ (root)`.
